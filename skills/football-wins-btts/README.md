# Wins / BTTS — read first

**Purpose:** find supported match-winner and BTTS directions. Follow project preferences; AI-Bets permits **BTTS Yes only** for future suggestions.

**Process:** verify fixtures → screen every game → deepen plausible cases → challenge evidence → complete XI/price/rule checks → journal decisions.

- Compare **both teams** using a broader baseline and recent 5–10 comparable matches where available: xG/npxG, shots/SOT, venue, opponent quality and distorted results.
- Assess both tactical directions: press/build-up, width/cover, transitions, set pieces, current personnel and draw risk.
- For BTTS, establish each side's scoring route separately. For wins, explain the opponent's resistance as well as the favourite's strengths.
- Keep failed observations, strongest counterarguments and missing evidence visible. Deepen close exclusions when warranted.

**Output:** source-linked justification, observed odds/time, clear status, material remaining checks and important passes. Final selections stay separate from research candidates; no fixed number is required.
